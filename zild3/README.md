# Zild3 — Expanded Final Revision

Zild3 is the expanded edition of the Zild rewrite. It preserves the zild2 chapter sequence and essential story while adding relevant scene work, character consequence, world-system detail, recurring Easter eggs, and appendix-ready questions. Additions were screened to reject repetition, generic atmosphere, and material that increases length without changing the reader’s understanding.

## Contents

| Folder or file | Purpose |
|---|---|
| `chapters/` | Seventeen expanded reader-facing chapters. Each falls between approximately 1.20x and 1.66x the corresponding zild2 chapter length. |
| `appendices/` | Ten detailed evidence files covering chronology, characters, Ark systems, Zild, ecology, AI, subplot payoffs, signals, culture, and risks. |
| `appendices_index.md` | Detailed appendix index and reading-order guidance. |
| `continuity_bible.md` | Canonical world, character, terminology, and sequence controls. |
| `easter_eggs_and_appendix_ledger.md` | Recurring motifs, planted details, and open questions. |
| `expansion_rubric.md` | Relevance gate used for every expansion. |
| `validation_report.md` | Final automated coverage, ratio, label, name, and link validation. |

## Reading order

Read the seventeen chapters in numerical order. Afterward, use the appendix index to move between the story and its evidence files. The appendices interpret and organize the book; they do not repair scenes that should stand on their own.

## Reader app

The companion static reader app is the Manus web project **zild-reader**. It renders the zild3 chapters and appendices as navigable Markdown, with chapter search, reading progress, adjacent-file navigation, and responsive archive layouts. Its visual direction is documented in the app’s `ideas.md` file under the Ash Archive approach.

## Source protection

The original source files and the zild2 rewrite remain unchanged. Zild3 is a separate expansion layer so the earlier revision can still be compared directly.
